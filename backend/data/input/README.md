# User-provided data
The source workbook `ncrb_crime_against_women_metropolitan_2024.xlsx` is retained here for reproducibility. It is the public NCRB Table 3B.1 (2022–2024), mirrored by OpenCity. The connected Delhi City series also uses NCRB Table 3B.1 (2020–2022); both references and the extracted five-year aggregate are recorded in `data/fixtures/ncrb_delhi_city_women_crimes.json`.

Place only datasets you are authorized to process here. Do not add unlicensed news text or victim identifiers. CSV, JSON, and JSONL are supported for user-provided imports.
